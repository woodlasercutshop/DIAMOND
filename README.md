# DIAMOND — мужская парикмахерская: запуск на GitHub

Языки приложения: қазақша, русский, English.
Структура файлов такая же, как у razzi-hair-site.

## 1. Выложите сайт на GitHub Pages
1. Откройте github.com и войдите в аккаунт.
2. Нажмите New repository.
3. Назовите репозиторий `diamond`.
4. Выберите Public.
5. Нажмите Create repository.
6. Нажмите Add file → Upload files.
7. Загрузите все файлы из этой папки, включая `.nojekyll`.
8. Нажмите Commit changes.
9. Откройте Settings → Pages.
10. В Branch выберите `main` и папку `/ (root)`.
11. Нажмите Save.
12. Подождите минуту.
13. Откройте ссылку `https://ВАШ-ЛОГИН.github.io/diamond/`.

## 2. Облачная база (Supabase)
Файл `config.js` пуст. Без облака приложение хранит данные только на одном телефоне.
Бот записи работает без интернета.

1. Откройте supabase.com и войдите в аккаунт.
2. Создайте новый проект для DIAMOND.
3. Откройте SQL Editor.
4. Вставьте содержимое файла `supabase.sql`.
5. Нажмите Run.
6. Откройте Project Settings → API.
7. Скопируйте Project URL.
8. Скопируйте ключ `anon public`.
9. Откройте файл `config.js` в репозитории GitHub.
10. Нажмите значок карандаша.
11. Вставьте URL и ключ между кавычками.
12. Нажмите Commit changes.
13. Подождите минуту и обновите страницу.

Таблица называется `dia`. Она не пересекается с таблицей `rz` проекта Razzi.
В шапке значок сменится с 💾 на ☁️. Это значит, что синхронизация работает.
Значок ⚠️ значит ошибку. Нажмите «Проверить облако» в Настройках мастера.

## 3. Установка на смартфон, планшет и компьютер
Приложение занимает всё окно на любом экране. На планшете и компьютере карточки идут в несколько колонок.
Кнопка «Установить приложение» есть в боковом меню и в разделе «О приложении».

**Android (Chrome)**
1. Откройте ссылку в Chrome.
2. Нажмите «Установить приложение» или меню ⋮ → «Установить приложение».

**iPhone и iPad (Safari)**
1. Откройте ссылку в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».

**Windows, Linux, Mac (Chrome или Edge)**
1. Откройте ссылку в браузере.
2. Нажмите значок установки в адресной строке или меню ⋮ → «Установить DIAMOND».
3. Приложение откроется в отдельном окне. Разверните окно на весь экран кнопкой «Развернуть».

**Mac (Safari)**
1. Откройте меню «Файл».
2. Выберите «Добавить в Dock».

## 4. Файл APK
1. Откройте pwabuilder.com.
2. Вставьте ссылку на сайт.
3. Нажмите Package for stores → Android.
4. Скачайте APK.

## Вход клиента (2FA)
1. Клиент нажимает «Запись».
2. Клиент вводит имя и телефон.
3. Клиент нажимает «Запросить код в WhatsApp».
4. Мастер открывает Настройки → Генератор 2FA или Клиенты → «Код».
5. Мастер отправляет клиенту 4 цифры в WhatsApp.
6. Клиент вводит код. Код действует 3 минуты.

## Вход мастера
1. Нажмите «Запись».
2. Введите номер WhatsApp мастера в поле телефона.
3. Нажмите «Продолжить».
4. Введите пароль.

Пароль по умолчанию: последние 7 цифр номера WhatsApp.
Смените пароль сразу: Настройки → Настройки мастера → Админ мастера.

## Код входа клиента: автокопирование
1. Клиент запрашивает код. Мастер видит запрос в «Входящих».
2. Мастер нажимает «Код» у клиента или «Скопировать сообщение» в Генераторе 2FA.
3. Приложение само копирует готовое сообщение. В нём код и инструкция, куда его вводить.
4. Сообщение написано на языке клиента.
5. Мастер нажимает «Открыть WhatsApp». Чат открывается с готовым текстом.
6. Клиент вводит 4 цифры или нажимает «Вставить код». Кнопка берёт код из скопированного сообщения.

## Удаление сообщений, заказов, клиентов
1. Откройте Настройки → «Сообщения и записи».
2. Выберите вкладку: Сообщения, Заказы (покупки и архив), Записи, Отзывы или Клиенты.
3. Отметьте то, что нужно удалить.
4. Нажмите «Удалить выбранные».
Кнопка «Выбрать запросы кода» отмечает служебные запросы кода.
Кнопка «Удалить всё во вкладке» удаляет всю вкладку.
При удалении клиента удаляются его сообщения, заказы, записи и отзывы.
Кнопка «Очистить всю базу» удаляет сообщения, заказы, записи, отзывы и клиентов. Нужно ввести слово УДАЛИТЬ.
Услуги, товары и настройки остаются.
Удаление нельзя отменить. Сохраните PDF до удаления.

## База клиентов в PDF
1. Откройте Настройки → «База клиентов в PDF».
2. Нажмите «Скачать PDF: все клиенты» или «PDF» у одного клиента.
3. Файл сохраняется на устройство: телефон, планшет или компьютер.
4. На iPhone и iPad откроется меню «Поделиться». Выберите «Сохранить в Файлы».
В файле: контакты клиента, записи, покупки, вся переписка, отзывы и бланк разбора обращения.
Бланк содержит причины: цена, качество, упаковка, обслуживание, отношение к клиенту.
Кнопка «PDF» есть и в списке клиентов мастера.

## Страница «О мастере» на планшете и компьютере
Фото работ идут в ленте, как в галерее. Лента листается сама каждые 3,5 секунды.
Автопрокрутка останавливается, когда курсор над лентой или когда вы коснулись ленты.
Стрелки справа и слева листают вручную. Нажатие на фото открывает его крупно.
На телефоне фото идут столбиком, как раньше.

## Заказы товаров и архив
1. Клиент оформляет заказ.
2. Мастер ведёт заказ: Принят → Готов к выдаче → Выдан.
3. После кнопки «Выдан» заказ уходит в «Архив покупок».
4. Архив есть у мастера (вкладка «Заказы») и у клиента (вкладка «Профиль»).
5. Заказ из архива изменить нельзя.

## Поделиться и пригласить
В «Профиле» и на странице мастера есть кнопки «Пригласить друга» и «Поделиться».
Кнопки открывают меню отправки телефона. Адрес ссылки на экране не показывается.
Если в тексте мастера есть ссылка, приложение показывает её кнопкой: «Открыть на карте», «Написать в WhatsApp» или «Открыть ссылку».

## Цены и товары
Цены услуг и товары в приложении — примеры.
Замените их в Настройки → Услуги и цены и Настройки → Товары.

## Важно
Политика базы в `supabase.sql` открытая. Она подходит для пробного запуска.
Не размещайте ключ `service_role`. Используйте только `anon public`.
Перед платным запуском добавьте серверную проверку кода входа.
